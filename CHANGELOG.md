# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-11-04

### Added

- Printable 7-day chart for caregivers and pill organizers (`--week`)
- Specific-weekday schedules ("every Monday and Thursday") with matching calendar repeat rules
- Midday timing ("with lunch", "at noon")
- Contributor docs, issue templates, linting and coverage in CI, release workflow

## [0.1.0] - 2026-11-04

### Added

- Label parser that abstains on error-prone abbreviations, ranges, tapers and other ambiguity
- Large-print HTML schedule, calendar (.ics) export, OCR with confidence-gated abstention
